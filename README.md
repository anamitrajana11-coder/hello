# Anamitra Jana · one-pager

A one-page introduction to Anamitra Jana's product design work, sent with outreach messages. It lives at [hello.anamitrajana.com](https://hello.anamitrajana.com/) and the full portfolio at [anamitrajana.com](https://anamitrajana.com/).

- `index.html`: the page. It is published with GitHub Pages and asks search engines not to list it.
- `CNAME`: the page's address, hello.anamitrajana.com (a CNAME record for `hello` at the domain's Squarespace DNS points to anamitrajana11-coder.github.io). Removing this file takes the page off that address.
- `css/tokens.css`: a copy of the portfolio's design tokens.
- `css/hello.css`: the page's layout and components.
- `assets/`: every picture, video, photo and logo the page uses (`assets/companies/`: the white Boston Bioprocess, Featurely and Toyota Mobility Foundation logos for the "Building products at" card), at full quality: the case studies' videos (each with a still frame) and the sharpest copy of each picture, up to 3840 px wide. Clicking a tile opens it large, like the portfolio's About page.
- `js/hello.js`: besides the testimonial deck, it loads the videos two at a time from the top once the page is up, and runs the preview.
